## 一、任务边界

任务1的目标是形成多款游戏的可复查运行结果，证明已经实际发现并分类兼容性或性能问题。它不要求在这一阶段修复所有发现的问题。

Dave 的启动、稳定性和输入修复属于任务2深度；Dave 的性能基线与优化前后对比属于任务3。两者可以作为任务1的证据来源，但不能替代“各种游戏”的覆盖要求。

1. 对本地 `games` 目录中的四款游戏各完成至少一轮有效真机启动测试：Dave the Diver、Stardew Valley、Escape from Duckov、Palworld。

## 四、公共测试基线

1. 使用 G3-P2 APK。该版本保留内置 Wine/rootfs 修复、Box64 0.4.5-dev、XKB 键盘兼容层和性能 CSV 工具，并修复 HUD 截获全屏触摸的问题。
2. Dave 的成功容器只用于 G3-P2 回归，不作为新游戏容器。Duckov 与 Palworld 分别新建容器，避免 prefix、注册表和组件互相污染。
3. 新游戏首轮统一使用 `1280x720`、Turnip/Zink、Box64 `Intermediate`、HUD `Full`，不启用 Wine 调试通道，不增加未经计划的启动参数。
4. Duckov 首轮使用 DXVK 3.0.2，并设置 `BOX64_UNITYPLAYER=1`；如果进程启动但无法出帧，第二轮才单变量切换 WineD3D，其他设置不变。
5. Palworld 首轮按 D3D12 路径使用 VKD3D 3.0.1，从 `Palworld.exe` 启动。只有日志证明启动器或 D3D12 路径失败后，才分别测试直启 Shipping 程序或 D3D11 路径，不在同一轮同时改变两项。
6. 首轮不追求最高性能，先回答“能否启动、能否进入、能否操作、是否稳定、是否存在明显性能问题”。发现问题后再决定进入任务2兼容性分析或任务3性能优化。

## 五、执行顺序

### T1-GATE：G3-P2 输入回归门槛

- [ ] HUD 外单指拖动可连续移动鼠标。
- [ ] Dave 中已经验证的触屏方向键仍有效。
- [ ] 长按 FPS 面板出现短振动；松手后 HUD 外鼠标仍有效。
- [ ] 导出最新 input-events 日志；存在性能 CSV 时一并导出。

门槛未通过时不测试新游戏，避免把 Winlator 全局输入回归误记为游戏兼容性问题。

### T1-DUCKOV-A：Duckov 标准基线

1. 新建独立容器并记录容器 ID，不复制 Dave 或星露谷容器。
2. 设置公共基线、DXVK 3.0.2 和 `BOX64_UNITYPLAYER=1`，为 `Duckov.exe` 创建快捷方式，不添加启动参数。
3. 冷启动一次，最多等待 5 分钟；记录是否出现窗口、Logo、主菜单、读档/新游戏和实际场景。
4. 若进入可交互界面，验证鼠标移动/左键与 `A` 键，随后运行至少 5 分钟，能进入场景则观察 10 分钟。
5. 正常退出或保留失败现场后导出最新 Winlator 日志、input-events 日志和 frame-rating CSV。
6. 只有 A 轮日志表明进程已进入图形初始化但没有首帧时，才安排 T1-DUCKOV-B 的 WineD3D 单变量对照。

### T1-PAL-A：Palworld 标准基线

1. Duckov 结果归档后再新建 Palworld 独立容器；不复用 Duckov prefix。
2. 设置公共基线与 VKD3D 3.0.1，从根目录 `Palworld.exe` 启动，不添加参数。
3. 最多等待 8 分钟，记录启动器、Shipping 进程、窗口、Logo、主菜单和实际场景的最远到达点。
4. 若进入可交互界面，验证鼠标移动/左键与 `A` 键，并观察至少 5 分钟；同时记录是否存在持续低帧率、严重卡顿或图形错误。
5. 导出本轮全部日志和 CSV。直启 `Palworld-Win64-Shipping.exe` 与切换 D3D11 只能作为后续两个独立变量，不在 A 轮混用。

## 六、结果分类

| 代码 | 分类 | 判定标准 |
|---|---|---|
| PASS-PLAY | 可游玩 | 进入实际场景，鼠标/按键有效，观察期内无闪退 |
| PASS-MENU | 部分通过 | 进入主菜单但未进入场景，或场景加载失败 |
| FAIL-START | 启动失败 | 主程序未创建、命令/路径错误或容器提前退出 |
| FAIL-BLACK | 黑屏/无首帧 | 进程存在且完成部分初始化，但观察期内无可见画面 |
| FAIL-CRASH | 闪退 | 游戏窗口或主进程出现后异常退出 |
| FAIL-INPUT | 输入异常 | 画面可交互但鼠标或标准按键无响应 |
| PERF-CANDIDATE | 性能候选 | 可以游玩，但持续低帧率、严重帧时间抖动或图形路径效率异常 |
