## 真机安装与测试

1. 在 Windows 上用 USB 数据线连接手机，选择“文件传输/MTP”，把上面的 APK 复制到手机 `Download` 目录。不要使用 adb，也不要把游戏目录复制回仓库。
2. 在手机文件管理器中点击 APK，按系统提示允许该文件管理器“安装未知应用”，然后安装。若手机提示签名不一致或版本冲突，不要卸载旧 Winlator；先把提示文字和当前已安装版本发回。
3. 安装前若已有旧 Winlator，先尝试直接覆盖安装。不要为了消除冲突直接卸载，因为卸载可能删除现有容器和配置。
4. 启动 Winlator，进入“设置 → 系统”：Wine Debug 打开，通道保持默认 `warn,err,fixme`；`Box64 Logs` 设为 `Minimal`；打开 `Save logs to file`，日志路径保持默认 `Documents/Winlator/logs.txt`。这几项只用于获得可分析日志，回传时必须注明已开启。
5. 新建师父专用容器，容器 ID 必须不是 10。设置 `1280x720`、Turnip/Zink、DXVK 3.0.2、ALSA、Box64 `Intermediate`、HUD `Simple`，环境变量保持空。
6. 在该新容器内打开 `E:\SIFU Deluxe Edition\Sifu\Binaries\Win64`，只对 `Sifu-Win64-Shipping.exe` 创建快捷方式；不要使用根目录 `Sifu.exe`，不要编辑容器 10 的原爆点快捷方式。
7. 在快捷方式设置中执行参数填 `-dx11`。启动前核对：容器 ID 不是 10；工作目录以 `SIFU Deluxe Edition\Sifu\Binaries\Win64` 结尾；可执行文件为 `Sifu-Win64-Shipping.exe`。看到 `MetalGearSolidVGroundZeroes` 或 `MgsGroundZeroes.exe` 就停止。
8. 首页只点击一次该师父快捷方式。无窗口时完整等待至少 5 分钟；若进入菜单，测试鼠标移动、左键和 `A` 键；进入实际场景后继续观察至少 10 分钟。记录窗口、黑屏、闪退、输入和最远到达点。

## 不使用 adb 导出日志

1. 结束测试后不要再次启动容器，否则 `startup.log` 和 `logs.txt` 可能被新会话覆盖。
2. 用手机文件管理器进入 `内部存储/Documents/Winlator/`，复制以下文件到新目录 `Documents/Winlator/T1-SIFU-A-20260824/`：`logs.txt`、`startup.log`。
3. 进入 `Documents/Winlator/input/`，复制本轮时间最新且包含本次会话的 `input-events-*.log`；文件末尾应尽量包含 `session_end`。如存在本轮新生成的 `Documents/Winlator/performance/frame-rating-*.csv`，一并复制；HUD Simple 通常不会生成该文件，不要因此改变测试配置。
4. 在 `T1-SIFU-A-20260824` 目录中新增一个文本文件 `result.txt`，记录手机型号、Android 版本、测试开始/结束时间、容器 ID、实际可见结果、等待时长、鼠标/左键/A 键结果和是否正常退出。可同时放入快捷方式设置页面截图，但不要放入游戏目录或存档。
5. 在文件管理器中压缩 `T1-SIFU-A-20260824` 为 `T1-SIFU-A-20260824.zip`，通过 USB 复制回电脑，或直接把这个 ZIP 文件发送给我。不要只发截图，不要发送 APK 以外的商业游戏文件。
6. 如果 `logs.txt` 不存在，仍发送 `startup.log`、最新 input-events 和 `result.txt`，并说明缺少 `logs.txt`；不要重复点击快捷方式补日志。
